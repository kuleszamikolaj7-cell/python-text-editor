# 📝 Python Text Editor

A simple desktop text editor built with **Python** and **PySimpleGUI**.

This project was created to practice Python GUI development, file handling, event-driven programming, and building desktop applications.

## ✨ Features

- Create new text documents
- Open existing text files
- Save and Save As functionality
- Change font family and size
- Support for UTF-8 text
- Simple menu-based interface
- Resizable text editing area

## 🛠️ Tech Stack

- **Python 3**
- **PySimpleGUI**
- **Tkinter file dialogs**
- **OS and IO modules**

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/python-text-editor.git](https://github.com/kuleszamikolaj7-cell/python-text-editor.git
```

### 2. Open the project folder

```bash
cd python-text-editor
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Run the application

```bash
python text_editor.py
```

**Note:** PySimpleGUI availability and installation requirements may vary depending on the version. The project should be tested with the documented dependency version.
